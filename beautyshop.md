# BeautyShop — Production E-Commerce Platform

BeautyShop is a production cosmetics e-commerce platform built for a real retail client in Tunisia.

## What I built

I worked across the full application lifecycle: frontend, backend APIs, database design, authentication, catalog operations, admin tooling, deployment and production fixes.

## Tech stack

- Next.js / React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Row Level Security

## Scale

- 15,000+ product records
- Large barcode-driven catalog workflows
- Multilingual FR/EN storefront
- Production admin and owner workflows

## Core features

- Product catalog, categories and brands
- Product search, filtering and pagination
- Product variants
- Customer authentication
- Shopping cart
- Guest cash-on-delivery checkout
- Order management
- Admin dashboard
- Role-based staff/owner access
- Automated order email notifications
- SEO and structured-data work
- Catalog import and synchronization workflows

## Engineering challenges

The project grew from a normal storefront into a data-heavy production application. That required handling large imports, keeping catalog operations practical for staff, improving page performance, enforcing stock/publication rules and maintaining clean role-based access.
