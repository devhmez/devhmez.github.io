# BeautyPulse — Retail Pricing Intelligence Platform

BeautyPulse is a private retail-intelligence application built to help a cosmetics business compare market pricing and identify product opportunities.

## What I built

I built the application architecture, protected dashboard flows, catalog import logic, barcode matching, competitor-data collection and pricing-analysis workflows.

## Tech stack

- Next.js / React
- TypeScript
- Supabase
- PostgreSQL
- REST APIs
- Web scraping / data ingestion

## Scale

- 15,000+ products
- 14,000+ primary barcodes
- Multi-source catalog matching
- Competitor comparisons across Tunisian e-commerce sites

## Core features

- Barcode-based product lookup
- Competitor price comparison
- Cost, stock and margin visibility
- Market and opportunity dashboards
- Matching engine using barcode/reference/name fallbacks
- Demand and pricing signals
- Private invitation-only access
- Row Level Security and server-side privileged access
- Import, verification and scraper health tooling

## Engineering challenges

The difficult part was not the dashboard UI; it was normalizing inconsistent retail data from several sources, matching products reliably, handling incomplete competitor data and keeping recommendations explainable instead of pretending weak data was certain.
